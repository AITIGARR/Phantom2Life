# Phantom2Life 1.5.2 — настоящие Polymer-блоки без чёрной доски

Fabric 1.21.11, Java 21, Fabric API, Polymer 0.15.2+1.21.11 **на сервере**. Клиентский мод не нужен.

## Исправления 1.5.2
- **Положение текста:** текст выровнен ближе к центру настоящего Polymer-блока; старые визуальные сущности перепозиционируются автоматически при обновлении блока, пересоздавать табличку не нужно.
- **Редактирование только ПКМ, без команд.**
- **Область клика:** у `interaction` исправлена нижняя граница (была на +0.5 блока от основания). Теперь кликабельна поверхность самого блока.
- **Редактирование:** нативный `SignItem` больше не открывает несовместимый редактор для `structure_void`. Сервер временно показывает ванильную табличку на **реальной позиции** блока, открывает четыре строки и сохраняет их в настоящий `SignBlockEntity`; после сохранения отображение `structure_void` возвращается.
- Отдельные ID блоков `naviyosha:invisible_sign` / `naviyosha:invisible_wall_sign`, Polymer и крафты сохранены. Ресурспак 1.5.2 не меняет vanilla sign texture.
- Проверка в игре на мобильном клиенте требуется; успешная CI-сборка и запуск headless сервера не проверяют клики и позиционирование глазами.

## Исправления 1.5.2

- Пустая невидимая табличка больше не кажется исчезнувшей: до ввода текста показывается тонкая строка-подсказка `[ ПКМ — написать ]`.
- Исправлена опасная обработка мобильных касаний: обычный удар по области таблички **не удаляет** настоящий Polymer-блок, а открывает редактор. Чтобы сломать табличку, используйте **Shift + удар** по её области.
- После установки редактор открывается по точным координатам только что поставленного блока, полученным из `SignItem.updateCustomBlockEntityTag`, а не вычисленным по соседнему блоку.
- Клиентский ванильный редактор получает настоящее содержимое `SignBlockEntity`, больше не создаётся `fake.setText()` со ссылкой на серверный мир, которое раньше отправляло непредусмотренные обновления.
- Все текстовые данные сохраняются в настоящем серверном Polymer SignBlockEntity; клиент видит `structure_void` и только `text_display` для букв.
- Все действия через ПКМ, **никаких команд**. Реальная работа интерфейса на мобильном клиенте должна быть проверена отдельно.

## Важно: новая архитектура
- Рецепт: мембрана фантома + любая обычная деревянная табличка (12 видов) → `naviyosha:invisible_sign`.
- Предмет устанавливает полноценный серверный блок `naviyosha:invisible_sign` или `naviyosha:invisible_wall_sign`, со стандартным `SignBlockEntity`. Текст, цвет, воск и сохранение хранятся **в настоящем блоке**.
- Polymer показывает клиентам `minecraft:structure_void` вместо таблички. Это невидимое ванильное состояние: никакой деревянной модели, никакой зависимости от альфа-канала, кастомных шейдеров или текстур.
- Для **отображения текста и кликов** сервер добавляет вспомогательные `text_display` и `interaction`. Они **не заменяют настоящий блок**; это только клиентская визуализация и интерфейс, поскольку без клиентского мода ванильный рендер текста таблички требует видимую модель таблички.
- Клик по области надписи открывает ванильный четырёхстрочный редактор через временный клиентский прокси. Запись сохраняется в SignBlockEntity. Есть обе стороны, красители, светящиеся чернила, воск; удар по хитбоксу разрушает реальный блок.
- Блоки/текст сохраняются после перезапуска. Вспомогательные сущности автоматически восстанавливаются по SignBlockEntity, если отсутствуют.
- Существующие старые таблички из версий 1.2–1.4 не мигрируются автоматически: уже установленные Polymer-блоки будут отображаться без деревянной модели после обновления; версии с обычным pale-oak sign нужно перекрафтить.

## Принципиально устранённая проблема
Ранее ресурспак пытался превратить текстуру `minecraft:pale_oak_sign` в прозрачную. Некоторые Android-рендереры показывали чёрную поверхность. **В версии 1.5.0 такая текстура и изменяющий её шейдер удалены**. Обычные pale-oak таблички больше не изменяются. Отдельный клиентский `text_display` всё ещё нужен для текста, но серверный блок остаётся настоящим.

## Установка
1. Положить `Phantom2Life-1.5.2.jar` в папку `mods` сервера, рядом с Fabric API и Polymer.
2. Подключить `Phantom2Life-resource-pack-1.5.2.zip` для иконок/переводов (графическая невидимость блока больше от ресурспака не зависит).
3. **Удалить предыдущие Phantom2Life-ресурспаки**, меняющие `assets/minecraft/textures/entity/signs/pale_oak.png` и `assets/minecraft/shaders/core/entity.fsh`.
4. Перезапустить сервер, отключить кэш старого пака, проверить обычные таблички и Polymer-таблички.

## Проверка
Сборка и автоматический запуск выделенного Fabric-сервера через GitHub Actions. Графическое тестирование на Android-клиенте необходимо отдельно. Флаги в эту версию не входят.
