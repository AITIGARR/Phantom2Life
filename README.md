# Phantom2Life 1.2.1 — Fabric 1.21.11

Серверный мод для ванильных клиентов. Два бесформенных рецепта рамок: фантомная мембрана + обычная или светящаяся рамка. Выходной предмет сохраняет ванильную иконку, получает блеск, читаемое имя и `entity_data` с невидимостью установленной рамки. Обычные рамки не меняются.

Невидимая табличка: фантомная мембрана + табличка любого из 12 видов дерева. Вид дерева сохраняется в базовом предмете и возвращается при поломке. Установленная табличка состоит из `text_display` и `interaction`; её корпус невидим, текст виден. Данные сущностей сохраняются Minecraft вместе с чанком.

## Управление табличкой

- Поставить скрафченную табличку на верхнюю или боковую грань твёрдого блока.
- При установке сразу открывается стандартный ванильный редактор таблички на четыре строки. Пустая табличка показывает светящуюся метку `[ Написать ]`; при появлении текста метка исчезает. Клик пустой рукой открывает редактор повторно. Команда `/p2l text <сообщение>` остаётся запасным способом для одной строки.
- Кликнуть красителем по табличке для окрашивания текста.
- Кликнуть медовыми сотами для запечатывания. Воск не снимается.
- Ударить по табличке для возврата предмета.

## Установка

Java 21, Fabric Loader для 1.21.11 и Fabric API. Положить `dist/Phantom2Life-1.2.1.jar` в `mods/`. Ресурс-пак не содержит моделей и текстур, меняющих ванильные объекты; он служит для локализации. Для выдачи пака сервером:

```properties
require-resource-pack=true
resource-pack=https://raw.githubusercontent.com/AITIGARR/Phantom2Life/main/dist/Phantom2Life-resource-pack-1.2.1.zip
resource-pack-sha1=cdd9e02cd28b0d84d6e97b58a8f9a46df48c9bd0
```

Сборка исходников: Java 21, Gradle 8.14, `gradle build`.

## Ограничения

Для открытия ванильного редактора сервер временно отправляет клиенту прокси-блок таблички у нижней границы мира и перехватывает ответ. Реальный блок мира не меняется. При разрыве соединения во время редактирования окно закроется без сохранения. Невидимый белый фон настоящего баннера с видимыми цветными узорами без изменения общего рендера/текстур баннеров не реализуется на ванильном клиенте. Флаг не включён. Поддержка стен и пола у `text_display` использует положение и всегда разворачивает текст к игроку.

## Ручная проверка

Проверить крафт, установку на стену и пол, смену текста и цвета, воск, поломку и дроп; перезапуск сервера, выгрузку чанка, воду и два клиента. Проверить автоматическое открытие редактора и подсветку пустой таблички, в том числе для объектов предыдущей версии. Сравнить обычные рамки, таблички и баннеры с ванильным сервером. Автоматизированный игровой прогон не выполнялся.
