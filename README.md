# Phantom2Life 1.3.0 — Fabric 1.21.11

Только серверный Fabric-мод + ресурспак. Клиентский мод не требуется. Java 21, Fabric API.

## Новые таблички — настоящие блоки
Мембрана фантома + обычная табличка любого из 12 видов дерева = **Невидимая табличка (блок)**.

Результат сразу является ванильным `minecraft:pale_oak_sign`. Он размещается ванильным кодом как настоящий стоящий или настенный SignBlock/WallSignBlock, содержит SignBlockEntity и использует родной редактор текста Minecraft: четыре строки на обеих сторонах, красители, светящиеся чернила, воск, сохранение после перезагрузки, разрушение и дроп. **Никакие display/interaction сущности или фейковые AIR-пакеты при установке новых табличек не используются.**

Ресурспак делает прозрачной текстуру `assets/minecraft/textures/entity/signs/pale_oak.png`, поэтому табличка отображает текст без деревянной основы.

**Ограничения:** без клиентского мода Minecraft не распознаёт новый ID блока или индивидуальный вид установленной таблички по Custom Data предмета. Поэтому **все pale oak таблички**, включая обычные, становятся прозрачными с этим ресурспаком. При разрушении выпадает обычная pale oak табличка. Исходный вид дерева при крафте не сохраняется.

**Старые таблички 1.2.3:** уже размещённые сущности остаются доступными для снятия/редактирования; чтобы получить настоящий блок, сломайте старую, скрафтите новую и поставьте её.

## Рамки
Мембрана + рамка / светящаяся рамка = невидимая рамка соответствующего вида. Реализация рамок не менялась.

## Установка
1. `Phantom2Life-1.3.0.jar` — в серверную `mods/` (Fabric 1.21.11 + Fabric API).
2. `Phantom2Life-resource-pack-1.3.0.zip` — клиентам (можно через `resource-pack` и `resource-pack-sha1` в `server.properties`). Ресурспак необходимо принять.
3. Перезапустите сервер. Тестируйте на копии мира. Флаги не входят в этот мод.

Сборка `gradle --no-daemon clean build` (Gradle 8.14, Java 21); CI публикует JAR + ресурспак.
