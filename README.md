# Phantom2Life 1.0.1 — Fabric 1.21.11

Серверный мод добавляет два бесформенных крафта: мембрана + рамка и мембрана + светящаяся рамка. Результаты — ванильные предметы с отдельными компонентами с именем, лором и блеском, `entity_data` с `Invisible:1b`. Обычные рамки не меняются.

## Сборка

Java 21 и Gradle 8.14: `gradle build`. JAR из `build/libs/` положить в `mods/` сервера Fabric вместе с Fabric API. Клиентских модов нет. Zip содержимого `resource-pack/` выдать через `server.properties`:

```properties
require-resource-pack=true
resource-pack=https://raw.githubusercontent.com/AITIGARR/Phantom2Life/main/dist/Phantom2Life-resource-pack-1.0.1.zip
resource-pack-sha1=57fb02f499633d22ab9c8aa6ffbad34c53c130bd
```

## Ограничения

Настоящий баннер без ткани с видимым узором нельзя отрисовать ванильным клиентом без переопределения общих текстур/рендера баннеров. Настоящую невидимую табличку с vanilla sign editor также нельзя получить с помощью `text_display`/`interaction`: редактор работает с реальным блоком таблички. Поэтому эти рецепты и иконки исключены из релиза. Альтернатива для таблички — серверный display с текстом и редактирование командой; это иной интерфейс. Для баннера — отдельная плоская модель `item_display`, не настоящий баннер.

## Проверка вручную

На сервере 1.21.11 скрафтить и установить обе рамки, поставить в них предмет, сломать и проверить дроп. Перезапустить сервер и выгрузить чанк; проверить сохранение. Проверить воду и двух игроков. Поставить обычные рамки, таблички и баннеры и сравнить внешний вид и поведение с сервером без мода.
