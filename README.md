# Phantom2Life 1.1.0 — Fabric 1.21.11

Серверный мод для ванильных клиентов. Два бесформенных рецепта рамок: фантомная мембрана + обычная или светящаяся рамка. Выходной предмет сохраняет ванильную иконку, получает блеск, читаемое имя и `entity_data` с невидимостью установленной рамки. Обычные рамки не меняются.

Невидимая табличка: фантомная мембрана + табличка любого из 12 видов дерева. Вид дерева сохраняется в базовом предмете и возвращается при поломке. Установленная табличка состоит из `text_display` и `interaction`; её корпус невидим, текст виден. Данные сущностей сохраняются Minecraft вместе с чанком.

## Управление табличкой

- Поставить скрафченную табличку на верхнюю или боковую грань твёрдого блока.
- Встать ближе 5 блоков и ввести `/p2l text <сообщение>` — меняется текст ближайшей таблички. Это одна строка; переносы и стандартный редактор таблички недоступны.
- Кликнуть красителем по табличке для окрашивания текста.
- Кликнуть медовыми сотами для запечатывания. Воск не снимается.
- Ударить по табличке для возврата предмета.

## Установка

Java 21, Fabric Loader для 1.21.11 и Fabric API. Положить `dist/Phantom2Life-1.1.0.jar` в `mods/`. Ресурс-пак не содержит моделей и текстур, меняющих ванильные объекты; он служит для локализации. Для выдачи пака сервером:

```properties
require-resource-pack=true
resource-pack=https://raw.githubusercontent.com/AITIGARR/Phantom2Life/main/dist/Phantom2Life-resource-pack-1.1.0.zip
resource-pack-sha1=6a287da39a23d6fcd7ef0702eef389bed383b567
```

Сборка исходников: Java 21, Gradle 8.14, `gradle build`.

## Ограничения

Обычный редактор таблички клиент открывает для настоящего блока таблички; для невидимого `text_display` он не работает. Невидимый белый фон настоящего баннера с видимыми цветными узорами без изменения общего рендера/текстур баннеров не реализуется на ванильном клиенте. Флаг не включён. Поддержка стен и пола у `text_display` использует положение и всегда разворачивает текст к игроку.

## Ручная проверка

Проверить крафт, установку на стену и пол, смену текста и цвета, воск, поломку и дроп; перезапуск сервера, выгрузку чанка, воду и два клиента. Сравнить обычные рамки, таблички и баннеры с ванильным сервером. Автоматизированный игровой прогон не выполнялся.
